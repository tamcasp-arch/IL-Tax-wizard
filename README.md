# אשף הדוח השנתי (בטא 1.0.0)

אפליקציה מקומית לחישוב הדוח השנתי לשכירים ולעצמאים בישראל. האפליקציה קולטת טפסים, מעבירה אותם בקרה, מחשבת נקודות זיכוי, הצמדה וריבית, ומפיקה דוח PDF. היא רצה כולה בדפדפן, עובדת גם בלי אינטרנט אחרי הכניסה הראשונה, ואפשר להתקין אותה כאפליקציה במחשב ובטלפון.

> הכלי מחשב הערכה לפי כללי רשות המסים, והוא אינו ייעוץ מס. החישוב המחייב הוא של רשות המסים. לפני הגשה, כדאי לבדוק את התוצאה ב[סימולטור הרשמי לשכירים](https://www.gov.il/he/service/simulator-employee).

## מה יש בפנים

- **אשף בחמישה שלבים:** שנה ומסלול, טפסים, נקודות זיכוי, זיכויים וניכויים, תוצאה והגשה.
- **שנות מס 2020 עד 2026:** לכל שנה המדרגות, ערך נקודת הזיכוי והתקרות שלה. כל שנה נשמרת בנפרד.
- **קליטת טפסים:** 106, אישורי ביטוח לאומי, אישורים שנתיים מקופות, קבלות סעיף 46 ו־867.
  - **בלי מפתח API:** טפסי PDF דיגיטליים מפוענחים מקומית לפי קודי השדות שבטקסט (158/172, 042, 244, 045 ועוד). סריקות וצילומים עוברים זיהוי טקסט (OCR) בעברית ובאנגלית בתוך הדפדפן, בלי לשלוח את המסמך לשום מקום. בצילומים, אם קוד שדה נקרא לא נכון, האשף משייך לפי התווית המודפסת. בכל מקרה הכול עובר במסך הבקרה.
  - **עם מפתח API של Anthropic:** אפשר לפענח גם סריקות וצילומים, והפענוח מדויק יותר.
- **מסך בקרה:** המסמך מוצג ליד השדות שפוענחו, עם בדיקות עקביות. נתון שלא אושר לא נכנס לחישוב.
- **חישוב נפרד לכל בן זוג,** עם פירוט נקודות לכל ילד לפי גיל ולפי הטבלה של אותה שנה.
- **הפרשי הצמדה וריבית של 4%** לפי סעיף 159א, מתום שנת המס ועד מועד התשלום.
- **דוח PDF מסודר,** וגם סיכום בקובץ טקסט.
- **עצמאים:** מחזור, הוצאות או עסק זעיר (30%), 52% מדמי ביטוח לאומי, קרן השתלמות לעצמאים (4.5%), פנסיה כעצמאי (זיכוי 5.5% וניכוי 11%), אובדן כושר עבודה, ניכוי במקור מחשבוניות ומקדמות.
- **דפי מילוי לטפסים 135 ו־1301:** קודי השדות והסכומים לכל בן זוג, נקודות זיכוי לסימון, הערות ומסמכים לצרף, כ־PDF או בתצוגה מקדימה. קודי השדות לפי טופס 1301 לשנת 2025. זה דף עזר להעתקה, לא הטופס הרשמי.
- **טפסים רשמיים ממולאים:** הסכומים, ספירת הילדים לפי עמודות הגיל של כל שנה והסימונים בחלק א׳ נכתבים ישירות על טופס 135 או 1301 הרשמי של רשות המסים לשנים 2020–2025 (בתיקייה `forms/`). גם שמות, מספרי זהות ופרטי בנק נכתבים על הטופס. כתובת, טלפון וחתימות ממלאים ביד.
- **יועץ (עם מפתח API):** מנתח את התוצאה ומציע דרכים להגדיל את ההחזר.

## מבנה הקבצים

```
index.html              האפליקציה עצמה
runtime.js              הגדרות, מפתח API, גיבוי ושמירת קבצים
sw.js                   עבודה אופליין (service worker)
manifest.webmanifest    הגדרות ההתקנה כאפליקציה
icons/                  אייקונים
vendor/                 ספריות וגופנים (pdf.js, pdf-lib, html2canvas, jsPDF, Assistant, Frank Ruhl Libre)
vendor/tesseract/       זיהוי טקסט מקומי (נטען רק בפעם הראשונה שמעלים צילום, כ־11MB)
TERMS.md                תנאי השימוש (טיוטה)
forms/                  הטפסים הרשמיים 135 ו־1301 לשנים 2020–2025 (עמודי הטופס בלבד)
.nojekyll               מונע עיבוד של GitHub Pages
```

אין שלב בנייה ואין תלויות להתקנה. כל הקבצים סטטיים.

## העלאה ל־GitHub והפעלה ב־GitHub Pages

1. צרו מאגר חדש ב־GitHub, למשל `tax-wizard`.
2. העלו את כל תוכן התיקייה לשורש המאגר, כולל הקובץ `.nojekyll`. אפשר בגרירה בממשק האתר (Add file, ואז Upload files), או משורת הפקודה:
   ```bash
   git init
   git add .
   git commit -m "אשף הדוח השנתי"
   git branch -M main
   git remote add origin https://github.com/<user>/tax-wizard.git
   git push -u origin main
   ```
3. ב־Settings של המאגר, תחת Pages, בחרו Deploy from a branch, את הענף `main` ואת התיקייה `/ (root)`.
4. אחרי דקה או שתיים האפליקציה תהיה זמינה בכתובת `https://<user>.github.io/tax-wizard/`.

הקוד לא מכיל נתונים אישיים, ולכן אפשר להשאיר את המאגר ציבורי. הנתונים שתזינו נשמרים רק בדפדפן שלכם.

## הפעלה מקומית בלי GitHub

מתוך התיקייה:

```bash
python3 -m http.server 8080
# או: npx serve .
```

ואז פותחים בדפדפן את `http://localhost:8080`. אפשר גם לפתוח את `index.html` ישירות, אבל אז עבודה אופליין והתקנה כאפליקציה לא יפעלו.

## התקנה כאפליקציה

- **מחשב (Chrome או Edge):** פותחים את הכתובת ולוחצים על סמל ההתקנה בשורת הכתובת, או בתפריט על "התקנת אפליקציה".
- **אנדרואיד (Chrome):** בתפריט, "התקנת אפליקציה" או "הוספה למסך הבית".
- **אייפון (Safari):** בכפתור השיתוף, "הוסף למסך הבית".

אחרי ההתקנה, האפליקציה נפתחת בחלון משלה ועובדת גם בלי חיבור.

## מפתח API (לא חובה)

1. יוצרים מפתח ב־[console.anthropic.com](https://console.anthropic.com). השימוש בו כרוך בתשלום לפי צריכה, בחשבון שלכם.
2. באפליקציה לוחצים על "הגדרות", מדביקים את המפתח, ולוחצים "בדיקת חיבור".
3. אפשר לשנות את שם המודל באותו מסך.

**אבטחה:**
- המפתח נשמר ב־localStorage של הדפדפן במכשיר הזה בלבד. הוא לא נכלל בגיבוי ולא נשמר בקוד.
- אל תכניסו את המפתח לקבצים במאגר.
- המסמך נשלח ישירות מהדפדפן ל־Anthropic, רק כשמפענחים או שואלים את היועץ.
- בגלל שהמפתח שמור בדפדפן, האפליקציה מיועדת לשימוש אישי. אם תרצו לתת אותה ללקוחות, כל משתמש צריך להזין מפתח משלו, או שתוסיפו שרת ביניים.

## הפצה

- **תנאי שימוש:** בכניסה הראשונה המשתמש מתבקש לאשר אותם, והם זמינים תמיד בכפתור "תנאי שימוש". הנוסח ב־`TERMS.md` הוא טיוטה, ומומלץ שעורך דין יעבור עליו לפני הפצה לציבור.
- **עדכונים:** כשמעלים גרסה חדשה ל־GitHub ומעלים את `VERSION` ב־`sw.js`, משתמשים שהתקינו את האפליקציה יקבלו הודעה "הותקנה גרסה חדשה" עם כפתור רענון. האפליקציה בודקת עדכון בכל פתיחה ופעם בשעה.
- **שנה שלא עודכנה:** אם שנת המס האחרונה שנסגרה לא נמצאת בנתוני האפליקציה, מופיעה הודעה שהחישוב לשנה הזו עלול להיות שגוי.
- **בטא:** מומלץ לאסוף מהמשתמשים הראשונים טופסי 106 לדוגמה, ממוסכים, ממערכות שכר שונות, כדי לבדוק את הפענוח.

## נתונים, גיבוי והעברה בין מכשירים

- **איפה הנתונים:** הכול נשמר בדפדפן (localStorage), רשומה נפרדת לכל שנת מס. אין שרת.
- **גיבוי והעברה:** בהגדרות, "שמירת גיבוי" יוצר קובץ JSON. במכשיר השני פותחים "שחזור מגיבוי".
- **מה לא נשמר:** קובצי ה־PDF המקוריים. רק הנתונים שחולצו מהם.
- **פרטים מזהים:** שמות, מספרי זהות ופרטי בנק משותפים לכל שנות המס. מספרי זהות ופרטי בנק נשמרים (ונכללים בגיבוי) רק אם מסמנים "לשמור את מספרי הזהות ופרטי הבנק".
- **ניקוי דפדפן:** ניקוי נתוני האתר מוחק את הנתונים, לכן כדאי לשמור גיבוי.

## עדכון שנתי של נתוני המס

כל הנתונים נמצאים בתחילת הסקריפט ב־`index.html`:

| מה | איפה | מקור |
|---|---|---|
| מדרגות, ערך נקודת זיכוי, סף מס יסף, תרומות, תקרת פנסיה | `const TAX` | חוברת הניכויים של רשות המסים לאותה שנה |
| שילובי שיעור ותקרה ליישובים מוטבים | `TAX.yishuvCombos` | פרק ח בחוברת הניכויים |
| שנים זמינות | `const YEARS` | — |
| תקרת הכנסה קובעת לקרן השתלמות לעצמאים | `TAX.kerenSelfCeil` | חוברת הניכויים / כל זכות |
| מדד המחירים לצרכן | `CPI_DEC`, `CPI_KNOWN` | הלשכה המרכזית לסטטיסטיקה, מתפרסם ב־15 בכל חודש |

**טופס של שנה חדשה:** מוסיפים את הקובץ ל־`forms/`, ומפיקים את מיקומי השדות שלו (`FORM_POS`) ואת מספרי השורות (`FORM_LINES`) לפי קודי השדות המודפסים בטופס.

**אחרי כל שינוי בקבצים, שנו את `VERSION` ב־`sw.js`.** אחרת מכשירים שכבר התקינו ימשיכו להציג את הגרסה הקודמת מהזיכרון.
